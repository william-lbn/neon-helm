# 平台前置与部分安装退出

## 分层职责

平台层负责 Kubernetes、CNI、Service 转发、节点运行时、KVM、存储类、证书控制器及仓库连通。产品层的 Helm 管理 Neon 微服务、原生控制面和显式配置的计算资源策略。站点层输入仓库、存储类、命名空间、地域、节点选择和系统预算；运行 UID 和 Lease UID 只能在本次安装发现。验收层分别证明业务 SQL、真实物理内存、暂停恢复和退役。产品 Chart 不接管或硬编码 Kubernetes 发行版的节点文件路径。

## 静态 Pod 的真实硬限

静态 Pod 的 API 对象只是 kubelet 的镜像记录。只修改镜像 spec 不会把节点清单和进程资源一并改好；镜像和实际 QoS 不同时，kubelet 的状态更新还会因 QoS 不可变而失败。仅见 API limits 存在，不能认证 Host 普通工作负载已经有真实硬限。

本发行的预检要求静态镜像处于 Running，主容器 ready，并且 kubelet 容器状态中已确认的 memory limits 与声明一致；缺失、Pending 或不一致均拒绝。快照只保留静态来源和必要资源证据，不保存任意注解或 Pod 凭据。既不按 Pod 名称豁免，也不以运行时 requests、cgroup 统计或逻辑缓冲替代硬限与物理扩缩容证明。

平台修复应由原配置所有者操作，先观察 kube-proxy 容器、健康端点、Service 转发和节点清单，再修配置。RKE2 支持通过 `control-plane-resource-limits` 显式设置 kube-proxy 的资源，agent 也支持该设置；实际限额须按平台负载评估，不能把示例当成通用安全值。备份不应留在 kubelet 会扫描的静态清单目录。逐节点恢复后核实实际 CRI 内存上限、镜像状态、DNS、ClusterIP/NodePort 和共享平台健康，保留旧配置与回执。不能只删除 Pending 镜像记录来冒充修复。

## 首次建账与资源版本

标准安装显式使用 `initialize_mode: kubernetes-current-snapshot-v1`，要求固定的原 Node/Lease UID、Kubernetes 预算、Profile 和系统保留；与旧冻结 RV 配置互斥。每次尝试完整重读 Node/Pod 后，以本轮 Node RV 做 CAS。读后再变化则拒绝本轮；下一轮先读取原账本，已提交必须继续同一 Origin。残缺、损坏或带保护但缺账本的状态不得重置。版本推进不是身份更换，批准预算也不能随版本推进自动改变。

## 未开放控制面时退出部分安装

先保留原安装收据、原操作工具和冻结 Host 输入，再创建独立的卸载状态目录。仅在原状态为 incomplete、业务 NOT_RUN、控制面 Helm 从未提交、Host 激活 Helm 已确认完成、独占命名空间 UID 仍属于原安装且 VM 为空时，允许额外参数 `--incomplete-install-state` 与 `--original-operator-tools`。任何缺失/未知/更换的来源都拒绝。已经开放控制面或有业务 Operation 的站点继续使用正常退役与卸载流程。

部分退出沿正常卸载的 plan、stop-host-writers、end-host-domains、handoff-ordinary、cleanup-host-artifacts、uninstall、erase-data、verify-empty 顺序执行。每个动作均需保持同一原站点、原状态和原工具参数；主机只读核验器使用本发行固定 SDK 的二进制。中断后查询原请求和原阶段，不能从头重放。

尚未受保护的原容量写者只增加带本次 nonce 的独立退出观察保护，以保留正常终止证据；它不授予容量、不产生 Node 账本。已有域仍要求原生 SDK 核验完整账本、零 Compute 持有、原写者全部已终止、原 Lease 自然到期。完全未初始化的节点在原 UID、原 Lease、完整 VM/Pod 空域证明和写者终止都满足后只写本次退出标记，不伪造或删除账本。Pod 消失不代替进程退出，未知写保留原意图并阻止重放。

全部域结束后，才按原 UID/nonce 归还普通 Pod 保护并清理本次观察终结器。共享 CNI、kube-proxy、Harbor 和其他平台负载必须保留。物理卷清理仍限定在原 PVC UID 对应、显式存储根目录下的原子目录；失败现场和备份按私有资料归档，不能提交到 GitHub。

## 当前验收边界

源码检查通过不等于现场业务通过。必须在可信平台前置满足后，完成一次全新一键安装，再分别完成 PG17/PG18 API+SQL、原 Compute 物理内存自动增长与收缩、暂停恢复及正常退役，并完成最终发行与现场证据归档。新 Node 连续接入、生产 HA、公网入口、完整 TLS 和备份灾备另行验收，不能混写成本轮已完成。
